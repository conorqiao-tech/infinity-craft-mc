# Infinity Landscape preview

This source preview gives thirty-one familiar terrain textures an original Infinity palette: stone and deepslate, eight ores and their deepslate variants, dirt, sand, gravel, selected masonry, oak planks and logs, netherrack, End stone and obsidian. The PNGs are authored from blank pixels by `generate.py`; they do not copy Mojang or third-party art. Both editions use the same corresponding images, with edition-specific filenames. Existing block IDs, inventories, terrain and player builds are not rewritten; applying a pack would change their appearance.

These files are a **partial visual prototype**, not a complete Infinity overhaul or a release package. They are not added to the server's current Java or Bedrock resource packs and are not installed automatically. Java metadata targets Minecraft 26.4 Snapshot 5 resource-pack version 100.2. Bedrock names are based on the [official resource-pack samples](https://github.com/Mojang/bedrock-samples/blob/main/resource_pack/textures/terrain_texture.json); the exact supported Bedrock clients, pack stacking, tinting and appearance require real-device testing. A future integrated package needs a distinct version and separate live installation approval.

Run `python3 artwork/infinity-landscape/generate.py` from the repository to reproduce the assets. `python3 tools/build_infinity_landscape_preview.py --output <private-empty-directory>` builds separate review archives without installing them. The builder refuses to overwrite existing archives. Do not run either tool against a live server or world.
