# Infinity Landscape preview

This source preview gives fifty-seven terrain and crop textures an original Infinity palette, including stone and deepslate, eight ores and their deepslate variants, dirt, sand, gravel, selected masonry, eleven plank types, an oak log, netherrack, End stone, obsidian and amethyst geodes. Pale teal reflections mark the fully grown crystal tips. Younger amethyst buds retain their familiar appearance. Wheat has eight original growth stages, from low jade seedlings to tall, golden grain heads at harvest. It also gives twelve crafting materials and two wayfinding tools distinct Infinity-styled icons. The empty map is folded parchment with a teal compass rose and an ochre trail. The inventory spyglass has brass collars and a sea-glass lens. The preview uses the standard empty-map and spyglass sprite paths, so the icons can also appear wherever the client reuses those sprites. The PNGs are authored from blank pixels by `generate.py`; they do not copy Mojang or third-party art. Both editions use the same corresponding images, with edition-specific filenames. Existing block and item IDs, inventories, terrain and player builds are not rewritten; applying a pack would change their appearance, including wherever an item texture is reused.

These files are a **partial visual prototype**, not a complete Infinity overhaul or a release package. They are not added to the server's current Java or Bedrock resource packs and are not installed automatically. Java metadata targets Minecraft 26.4 Snapshot 5 resource-pack version 100.2. Bedrock names are based on the official [terrain](https://github.com/Mojang/bedrock-samples/blob/main/resource_pack/textures/terrain_texture.json) and [item](https://github.com/Mojang/bedrock-samples/blob/main/resource_pack/textures/item_texture.json) samples; the exact supported Bedrock clients, pack stacking, tinting and appearance require real-device testing. A future integrated package needs a distinct version and separate live installation approval.

Run `python3 artwork/infinity-landscape/generate.py` from the repository to reproduce the assets. `python3 tools/build_infinity_landscape_preview.py --output <private-empty-directory>` builds separate review archives without installing them. The builder refuses to overwrite existing archives. Do not run either tool against a live server or world.
