# Convergence and Aurora refresh — explore.19

Original artwork generated with the built-in `image_gen.imagegen` tool, then mechanically cropped, resized with nearest-neighbor sampling and packed into Minecraft UV rectangles. Generation itself was not performed by a local script or API-key workflow. The raw source PNGs and the flat armor/inventory previews are included here. These previews show the asset pixels, not screenshots from a Minecraft client.

`uv-manifest.json` records source crops, destination UV boxes and production PNG checksums. The two worn armor textures are 128×64 (twice the vanilla layout dimensions), with complete opaque head, body, arm and leg faces and transparent unused regions. The Convergence visor is part of the new helmet; its legacy separate overlay is not layered on top. The unchanged original wing sheet remains in use. The 24 distinct gear sprites produce 25 64×64 icons; the two different wand functions share collection artwork. Icon crops follow the actual object bounds so adjacent rows cannot leak into another sprite. Every original user-supplied PNG remains unchanged.

Java with the server resource pack uses the full custom armor and item models. Explore.20 also selects these designs through Bedrock native netherite and dyed-leather worn layers and inventory textures. Normal gear of the same materials shares the patterns while the pack is active; leather retains native dye tinting, including Ember/backpack colors. Native elytra shows the Convergence chestplate plus wings without changing native flight animations or item components. Mapped weapons, mining tools, ingot and wands use their refreshed sprites. Bows, crossbows, arrows, shields and totems retain native Bedrock artwork. Resource-pack revision 20 invalidates older cached pack versions.

## Final generation prompts

### Convergence armor

Use case: style-transfer. Asset type: Minecraft worn armor texture atlas, not a character skin or a rendered character. Edit target: the supplied Convergence humanoid armor 64x32 PNG. Create a fresh premium cosmic armor design: obsidian and deep indigo segmented plates, bright cyan luminous trim, restrained violet edges, a crisp angular star/core centered on the chest, a clean narrow cyan helmet visor, purposeful gauntlet lines and boot cuffs. Original Minecraft pixel art, readable at game scale. Follow the EXACT original vanilla armor UV layout: head UV envelope x0..31/y0..15, leg x0..15/y16..31, torso x16..39/y16..31, arm x40..55/y16..31. Keep every cube face in precisely its original location, same 2:1 aspect ratio, transparent unused atlas pixels. The texture sheet must remain flat and unwrapped, with no figure, perspective, text, labels, grid lines, extra panels, or background. Sharp nearest-neighbor square pixels and limited purposeful palette, not blurred gradients. The helmet must have visible dark plate around its visor; chestplate, leggings, boots and arms must all be complete. Keep transparent unused regions. Output only the texture atlas.

Tool settings: referenced original Java `humanoid/armor.png`; transparent background enabled.

### Gear inventory atlas

Use case: stylized-concept. Asset type: production Minecraft inventory sprite atlas. Generate ONE transparent rectangular atlas with EXACTLY 6 equal columns and 4 equal rows (24 separate icons), all cells identical size. Each object is centered entirely inside its own cell with generous transparent margins. Crisp Minecraft pixel art, about 32 logical pixels per cell, with hard square pixels and no blurring. Theme is premium cosmic gear: obsidian/indigo plates, cyan luminous edges, restrained violet rim accents and little silver highlights. Aurora armor (first four objects of row two) instead uses midnight teal, mint glow, pale icy silver and violet aurora ribbons. Row 1 LEFT TO RIGHT: Convergence helmet; Convergence chestplate; Convergence leggings; Convergence boots; cosmic sword; cosmic mace. Row 2 LEFT TO RIGHT: Aurora helmet; Aurora chestplate; Aurora leggings; Aurora boots; cosmic spear; cosmic shield. Row 3 LEFT TO RIGHT: cosmic pickaxe; cosmic axe; cosmic shovel; cosmic hoe; cosmic bow; cosmic crossbow. Row 4 LEFT TO RIGHT: cosmic metal ingot; cosmic star totem; cyan-tipped infinity arrow; violet-tipped void arrow; amber-tipped starfire arrow; cosmic building wand. Armor icons must show recognizable complete silhouettes, helmet with visor, chestplate with shoulders, separated legs, pair of boots. Tools have bronze/dark hafts and cyan cutting edges. All weapons/tools point diagonally from lower left to upper right where practical. No text, labels, numbers, borders, grid lines, additional objects, checkerboard, drop shadows, photoreal lighting or background. Output ratio 3:2. Uniform spacing is essential because the atlas will be sliced into individual game icons.

Tool settings: new generation; no reference images; transparent background enabled.
