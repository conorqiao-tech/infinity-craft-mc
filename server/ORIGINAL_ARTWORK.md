# Original Infinity artwork and inventory — explore.27

Convergence has pearl-white, midnight-blue and cyan plates with amber stars. Aurora uses jade, mint and lavender; Ember uses charcoal, copper and orange. The backpack has a sand/slate expedition style. All ten Infinity building materials and the registered gear sprites have original artwork. Ordinary leather, netherite and world-block textures stay normal.

## Find the sets

1. Enter **Creative** from Infinity Menu. Select the **Infinity Gear Picker** compass in your inventory/hotbar.
2. Choose **Aurora Set** or **Convergence Set** at the bottom. Tap a piece to receive the actual item in your hotbar. **All Infinity gear** returns to tools, gadgets and blocks; Next opens page two.
3. **Infinity Menu → Armor & tools → inventory** adds missing equipment directly to empty slots. If there is not enough room, clear slots and select it again. Existing items are preserved.
4. **Armor, tools & blocks → inventory boxes** gives five real shulker boxes: Convergence, Aurora, Ember and two tools/block boxes. Place and open a labeled box to take its contents. Clear five slots first.

These are real player-inventory items. The pinned Geyser build cannot safely supply Infinity items by dragging its custom Creative search entries. A modded Java client also has the custom Creative tab; server-only Java and iPad use the real collection picker and boxes without an extra client mod.

## Chestplate and flight

**Convergence Armor Chestplate** (`convergence:cuirass`) is solid chest-slot armor with the existing full Convergence set powers. Its distinct recipe uses seven Infinity Ingots surrounding a normal netherite chestplate. The original winged chestplate recipe is unchanged.

**Infinity winged chestplate** keeps the existing `convergence:chestplate` ID, saved items, glider component and flight controls. It is a separate chest-slot choice; both chest-slot items cannot be equipped at once. Either completes the existing helmet/leggings/boots set.

Bedrock static armor and backpacks use thirteen item-specific custom attachables, without native leather/netherite overrides. The wing item retains native elytra animations and shared elytra artwork: ordinary Bedrock elytra also show that artwork while this pack is active. Native shield, totem, bow, crossbow and arrows retain their ordinary Bedrock images and controls; pack-enabled Java has their fresh sprites. Java without its pack retains complete native fallback equipment.

Aurora, Ember and backpack artwork remains cosmetic. Backpack storage, mode inventories, earned unlocks and both AI approval gates are unchanged. Native Tidewarden/other Studio outfits retain their established trimmed Minecraft equipment; no extra outfit IDs or capabilities are introduced here.

## Device check after installation

Rejoin and accept the updated server resource pack. Each prepared update advances the pack and module revisions so Bedrock can refresh its cached artwork. Inspect all four equipped pieces of each set, the inventory icons and ordinary leather/netherite beside them. Swap the solid Convergence chestplate for wings, launch with rockets, glide and land, then re-equip the solid armor. Test collection pickup with an occupied hotbar and a full inventory. Reconnect and check your items.

Automated resource/native/bridge checks cannot prove Java/iPad rendering, touch input or authenticated flight. Report the piece and edition if an appearance is wrong. Source/package and live installation states are reported separately; this document is not proof of installation.
