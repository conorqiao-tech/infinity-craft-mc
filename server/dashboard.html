Set up your welcome area

As an operator in Minecraft, stand in a clear 25×25 grassy area and run /community buildspawn. It creates a lit plaza and sets spawn. Use /community setwarp market to make shared destinations. Grass/dirt/snow are reshaped. Other blocks and containers stop the build.
