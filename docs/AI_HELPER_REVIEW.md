# Helper expansion review — October 1, 2026

The owner chose six helper profiles, upgraded golem squads rather than player bots, and a code-change request workflow that requires in-game owner approval followed by live Codex source review and testing. Planned supporter prices are Go $50, Plus $75, Pro $100 and Ultra $200 USD/month; checkout remains unavailable.

The requested Gemini/Claude/Git consultation used the guarded local helper in a separate directory with relevant source excerpts and no private configuration. Gemini returned advice with `gemini-3.8-flash-high` selected and high effort requested. The execution-denial hook was verified. Antigravity reports the selected model but has no per-model usage evidence, and effective reasoning was not independently measured. Claude Opus 5.5 was requested with max effort; the request timed out after 300 seconds and was terminated without a retry or a usable review.

Useful Gemini recommendations were checked against implementation and tests: keep navigation separate from profiles; migrate old rosters explicitly; include unloaded helpers in owner/global limits; recheck owner identity and permissions on menus; prevent inventory-icon transfers; share API quotas across helpers; and keep model replies away from command dispatch. Its prediction of severe performance problems was not treated as a measured benchmark. The roster remains bounded at six helpers per owner and 24 per server; public-server load testing is still required.

Codex's independent review found and fixed two concrete issues: cancelled code requests could exceed the history bound and become unreadable after restart, and API snapshots could report a saved dimension rather than the loaded helper's actual dimension. The former has a repeated-cancellation regression test. Native menu tests initially called custom screen overrides without the Minecraft remapping context; the tests now call through Minecraft's screen-handler type.

Code requests are inert text records. Local-console review and completion record the operational workflow; Minecraft cannot authenticate Codex itself or independently verify a Git commit and its tests. Those checks remain part of the live source review. External AI replies have no tools, and recent Minecraft snapshots do not cause automatic network requests.
