# Infinity Armor Hub website source

This is the static guide used at [Infinity Armor Hub](https://infinity-armor-hub.vercel.app/). It explains the shared Java + Bedrock server, game modes, rewards, and joining. Vercel hosts this website; the host Mac runs the Minecraft world and its private control panel.

Edit `catalogue.json`, `site-template.html`, `dist/style.css`, and `dist/app.js`. Regenerate the HTML with:

```sh
python3 build_site.py
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Open `http://127.0.0.1:8765/` locally to preview. The build writes `dist/index.html`, which is intentionally untracked here. Release ZIPs and guide downloads must be produced and checked separately before deploying the complete `dist` folder to the `qiaokans-projects/infinityhub` Vercel project; `dist/downloads` is excluded from Git because it contains generated archives. The artwork in `dist/assets` comes from the supplied Infinity Armor textures. Do not put current tunnel addresses, owner-panel links, or private settings into the static site.

The installable guide uses the same origin and starts at the hub homepage. Postcard Pairs, Postcard Circuit, Circuit Conductor, the two-voice Counterpoint challenge, Chord Seal playback, Seal Cipher, Cipher Refrain, Refrain Cadence, Cadence Pennant, Pennant Fanfare, Pennant Chorus, Chorus Baton, Infinity Loop, Loop Inlay, Inlay Prism, Prism Crossing, Lantern Walk, Star Survey, Midpoint Beacon, Beacon Relay, Ribbon Return, Star Lens, and Star Trace at `/field-guide/#pairs` and Coda Studio at `/field-guide/#studio` are available in the hosted Field Guide. The website edition builds on the private Claude Field Guide and lives in `dist/field-guide/index.html`. The build versions the guide worker from the offline shell’s bytes. Generated release downloads stay outside the offline cache.

The Workspace link opens `/workspace/` on the same site. Visitors supply their own OpenAI API key and can submit one selected UTF-8 text file per request. The app sends it to GPT-6 Luna through `/api/workspace`, holds no local or server history, and lets the visitor review and download a proposed copy. The key, prompt and selected text are processed by Vercel and OpenAI. Deploy the website project root with `dist/`, `api/`, `package.json` and `vercel.json` together so the API is available. Run `npm test` from `website/` for the mocked API checks.

To check Counterpoint against a running build, make Playwright available to Node and run `node website/qa/counterpoint.cjs <site-origin>` from the repository root. Set `CHROME_BIN` to use an installed Chrome executable. The test plays all six routes by keyboard with sound on and off and checks the timing and pitches of the live and stamped phrases. It also checks seal playback after a circuit change and reload, repeated notes, and rejection of unknown saved formats.

Use the same browser setup with `node website/qa/seal-cipher.cjs <site-origin>` to check the missing-instrument game, including repeated pitches, duplicate guesses and seal playback independence. The same check performs the three missing voices in both directions and verifies the solo pitches, silent hints and final triad. After each refrain it tries every solo knot, rejects both pairs containing the soloist, checks the simultaneous answering duet, and plays the optional full chord.

The Field Guide keeps the last pennant the player chooses after a correct cadence. Both Guide and Postcard Pairs show it after reload. A new performance replaces the saved design only when the player keeps it. A kept pennant plays a two-beat fanfare even with no seal. The browser check also compares the solo and answering pitches, tab switching, restart, mute and failed saves. Pennant Chorus collects one performed solo per instrument until all three sound together. Its score lasts for the session. The browser check verifies a chord assembled from different pennants and replacement of a collected pitch. Chorus Baton steps through the completed score in first-collection order or in reverse before playing the trio together. Guide and Postcard Pairs share the current beat. Starting the next collection or reloading clears the baton. Infinity Loop lights a separate arc for each completed direction. Ringing the two outer voices preserves the current baton beat. Both panels share the loop for the session. Ringing also opens a Loop Inlay. The middle instrument and its collected pitch set the diamond once per ring. Wrong guesses leave the round open. Cut prism keeps the solved score across reloads. The left facet plays its first two voices and the right plays its last two. The active trio can change independently. Prism Crossing asks for the two outer voices of a saved prism. Match their facets in either requested order. The first answer plays two voices and the second plays all three. Wrong answers keep your place, and a reload returns the prism to free play. Lantern Walk opens after a completed crossing. Visit three distinct lantern posts within 12 blocks of each other to sound the three solos in crossing order and draw a constellation. Star Survey asks which visited post faces a longest opposite span, counting ties. Surveying it plays the two far voices once and marks the chosen viewpoint and baseline. Cairn at (7, 4) gives the map a close comparison against the eight-block Arch–Pool span. Midpoint Beacon uses the span selected in Star Survey. Aim at a closest grid cell to its midpoint to light a beacon and hear the observing lantern’s solo. The flat map supplies the glass height. Beacon Relay visits the two ends of the surveyed span in order of distance from the selected glass. Either endpoint can lead a tie. The first plays its saved solo. The second completes the full chord and draws an infinity ribbon. Ribbon Return recalls the actual last endpoint from the lit glass. Visit the observer, then the original lead, to sound the endpoint duet and light the center star. Star Lens matches the observer’s chart to cyan, purple or orange glass and projects the original three-by-three Star Loom pattern. A matching lens can repeat the display silently. Star Trace maps the projected chart’s columns to the three lanterns in visit order. Either of two tied columns can win. The chosen stop plays once and its double underline lasts for the walk.
