OWNER HELPER SQUAD

Six helpers. Six AI modes.

OP4 owners select Infinity Menu → AI Helpers → Create your first helper. A named iron golem appears beside you on clear ground. Choose its icon for modes, Follow, Guard, Stay, and a visible status report. The host can connect real Codex and use the Ask Codex button with limited Minecraft facts.

Primitive · Regular

Choose a combat-ready Primitive helper or the standard follow/guard profile. Both offer local help by default and real Codex answers when the host enables that provider.

Ultimate Finals · Debug

Ultimate Finals shares targets, predicts pursuit and rotates clear-air leap/dive attacks with ordinary golem damage. Debug shows health, location and pause reasons. These are golem tactics, not actual spear, mace or elytra equipment. Orders last up to five minutes and obey PvP and team rules.

CLI · API

Save a code-change request for owner and live Codex review, or ask AI using limited Minecraft facts. Codex uses the host’s signed-in account; the OpenAI API is an optional separate provider with API charges. Questions share a request limit, and answers cannot approve or execute changes.

Player targeting and server actions wait for owner approval and live Codex review. Use /agent ceasefire or the menu to stop your own squad. Chat cannot run commands. Helpers are server-controlled vanilla golems, with six slots per owner and 24 across the server.

ANOTHER WAY TO UNLOCK

Survival item trades

These trades spend Minecraft items, never USD. Trade items instead of completing the achievements.

Preview a trade with /trade <id>. When you are ready, add confirm: for example /trade rank-go confirm. Your unlock is permanent; items are spent once.

$TRADE_ROWS
UnlockItems to exchangePreview command

Trades work in Survival outside combat. Carry ordinary, unmodified items in your main inventory or hotbar; named or enchanted items, armor, offhand and stored chests are excluded. Missing items and already-owned unlocks are not charged. Cosmetics remain achievement rewards.

JOIN THE SHARED WORLD

Play from Java or Bedrock.

Ask the host for the server hostname and separate Java and Bedrock ports. A configured Dynu hostname stays the same when the home IP changes; free Pinggy tunnel addresses are temporary. This guide site does not host the Minecraft world.

01

Java on a computer

Use Minecraft Java 1.21.11. Open Multiplayer → Add Server and enter the Java host and port the owner gave you.

02

Bedrock on iPad

Sign in to Microsoft/Xbox, then tap Play → Servers → Add Server. Enter the Bedrock host and separate UDP port.

03

Accept the pack

Join and accept the server resource pack for the custom looks. Friends do not need a hosting or DNS account.

Host: keep the Mac awake, start the world with Start-Mac.command, configure your Dynu hostname and router forwarding, then run Start-Dynu-Mac.command to keep its IP updated. Share the saved hostname and game ports. Your private dashboard stays on your Mac.
