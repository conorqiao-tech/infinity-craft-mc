ANOTHER WAY TO UNLOCK

Survival item trades

These trades spend Minecraft items, never USD. Trade items instead of completing the achievements.

Preview a trade with /trade <id>. When you are ready, add confirm: for example /trade rank-go confirm. Your unlock is permanent; items are spent once.

$TRADE_ROWS
UnlockItems to exchangePreview command

Trades work in Survival outside combat. Carry ordinary, unmodified items in your main inventory or hotbar; named or enchanted items, armor, offhand and stored chests are excluded. Missing items and already-owned unlocks are not charged. Cosmetics remain achievement rewards.

JOIN THE SHARED WORLD

Play from Java or Bedrock.

Ask the host for the current address and port. The free remote connection changes after about an hour. This guide site does not host the Minecraft world.

01

Java on a computer

Use Minecraft Java 1.21.11. Open Multiplayer → Add Server and enter the Java host and port the owner gave you.

02

Bedrock on iPad

Sign in to Microsoft/Xbox, then tap Play → Servers → Add Server. Enter the Bedrock host and separate UDP port.

03

Accept the pack

Join and accept the server resource pack for the custom looks. You do not need a Pinggy account.

Host: keep the Mac awake, start the world with Start-Mac.command, then run Start-Pinggy-Mac.command and share its latest addresses. Your private dashboard stays on your Mac.
